## New offline operator tool

`scripts/audit-story-synthetic-stages.mjs` consumes one operator-protected synthetic diagnostic JSON locally and prints ONLY fixed stage names, word counts, exact normalized beat/choice comparisons and missing-stage warnings. It never prints any raw text, character names, identifiers, paths, story paragraphs, generated validation prose or full payload. The report explicitly sets `literary_quality_verified=false` and `root_cause_identified=false`. This is an informational audit, **not a deterministic editorial rejection gate**, child-facing feature, provider request or production change. It recognizes an unwrapped schema-1 payload or an object with `.payload` containing that payload. It rejects unknown and repeated stage types and unrecognized schema. The synthetic-only regression `scripts/check-story-stage-audit.mjs` is included in the normal `check:story-ai-split` command. Do NOT put real diagnostic files, raw outputs, screenshots or account identifiers in the public repository, GitHub artifacts or logs.
